# monopoly
Разработка игры "Монополия с перекрёстком". Источником вдохновения стала настольная игра созданная на основе оригинальной Монополии, однако существенно доработанная в отличии от классической версии игры. 
Создание приложения позволит протестировать игровые механики. Особенность монополии с перекрёстком - наличие перекрёстка в центре с дополнительными видами имущества.
Преимущество данной игры в том, что в классической версии спустя несколько кругов игра надоедает из-за постоянного хождения по кругу и очевидности победителя.
В Монополии с перекрёстком имеется возможность обходить опасные участки большого круга, а среди карточек Chance есть такие, которые переворачивают игру - Национализация, Диверсия, Монополизация и другие.

## Использование
1) Сохраняем файлы из репозитория на комп:
    - Открой проводник в windows. Выбери папку (C:\Users\monopoly) куда хочешь загрузить шаблон приложения
    - В пути напиши `CMD` и нажми ENTER
    - В CMD пиши: `git clone https://github.com/denisovv2001/monopoly-crossroads` и нажми ENTER
    - Открываем папку monopoly-crossroads
2) Запускаем файл main.py при помощи python
    - пользователь увидет в консоле текст
        ```cmd
        Нажмите любую клавишу для начала
        ```
    - После нажатия любой клавиши будут созданы игровые ячейки и будет выведено следующее сообщение:
        ```cmd
        Успешно создано 53 игровых полей 
        Игрок "Vas", Находится на поле с индексом 0
        collect $200 salary as you pass GO
        Введите t для броска кубиков: 
        ```
    - Далее пользователь бросать кубики и перемещаться по полю
    путём нажатия на клавишу `t` на клавиатуре, когда пользователь будет проходить круг, то его сумма денег будет увеличиваться. Как только сумма будет > 1600 программа завершится.
